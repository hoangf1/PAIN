## What was added

- **The H1 and H5 fields of run 10** (CR-172428 App. D pp. 230, 234). Every input row (L = 10–19) is printed; only rows PAIN generates are cut at the page bottom. Each value was read by eye and checked against its printed copy in the lower quarter: amplitudes as an exact mirror, phases by PAIN's lower-quarter rule within 0.3°. The cut rows (H1 L = 1, H5 L = 1–2) are generated by that rule.
- **The rule** is App. A item 5's `DELPH = 2·B·IH·ALPHAL(L)`, with ALPHAL the angle at the propeller hub between the propeller line and the grid line. It reproduces every printed lower-quarter phase of H2–H4 to 0.1° at all 16 stations.
- **The upsweep side.** Both propellers turn the same way, so PAIN runs the downsweep and the upsweep side and adds them (p. 164). App. A item 5 swaps the field about the propeller line. The printed amplitudes are already mirror-symmetric, so the swap must move the phase too; the code mirrors the whole field (`r172428_flight10_inputs(; sweep = -1)`).
