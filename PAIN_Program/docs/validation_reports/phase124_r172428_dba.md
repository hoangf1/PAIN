both" (dB and dB(A)).

## Where both exist

For the Commander 695A, NASA never ran PAIN (CR-178004 compares only with two simplified procedures), so only
experiment exists there (AC_C695A_DBA). CR-172428 prints, for the 1.016 m test article at 3000/4000/5000 rpm, both
NASA PAIN's predicted space-average tones H1–H3 and the measured space averages (196 microphones; Table 10, App. B
p. 206). These are the only interior levels where this code, NASA's PAIN and a measurement share the same inputs.

## Cases (criteria fixed 2026-11-04 before each first run)

The tonal level is the energy sum of H1–H3, A-weighted at each tone's frequency for dB(A) and unweighted for dB,
formed the same way for all three. Tolerances copied unchanged from the parents (R172428_CODE ±3 dB, R172428_EXP
±4 dB), required at each rpm. Each runs exactly the parent's run.

## Reading (post-hoc, no verdict)

- The code in its default form is within 0.9 dB(A) and 0.7 dB of NASA's printed sums at all three rpm, and within
  1.2 dB of each of NASA's nine printed tones. This is not an independent pass: the default form's two tone-sum choices
  (q = 0 cabin modes uncoupled, η_n per mode) were taken from these printouts in Phases 92–93.
- Against the measurement, the code misses where NASA's PAIN misses (H1 at 3000 and 5000 rpm, −14 to −18 dB): the gap
  is the method's, reproduced, not added by the recreation.
