# τ_t of the Phase III sidewall at 100–400 Hz: variants (plan 19e)

Generated by `scripts/checks/check_tau_t_variants.jl`. Criteria fixed 2026-10-20 before the run (`IMPLEMENTATION_PLAN.md`, phase 19): each variant's τ_t recorded; a variant that makes τ_t ≤ 1 at 200 Hz is a finding, not adopted; if NASA prints a τ_t curve for Phase III, within 3 dB of it. Matrices rebuilt in the script (no `src/` change); τ_t = |a11|⁻² + τ_t^m (Eq. A.22) with the mechanical path of `phase3_trim`.

**NASA's printed τ_t:** none. Figures A-2, E-13, E-14, E-15 and E-25 print the insulation properties, absorption and loss factors, not a τ_t curve (checked against the list of figure captions of CR-3813 App. A and E), so the 3 dB comparison has no target.

**Trim loss factor used by NASA (CR-3813 App. E p. E-24, read from the page image):** "The two calculated loss factor spectra in Figure E-15 assumed trim loss factors of 0.5 and 1.0" and, for the predicted interior levels of Figs. E-16/E-17: "with an assumed structural loss factor for the trim of η_T = 0.5". The registered 18b run used `phase3_trim`'s default η_lining = 0.05 (register f, chosen for the aircraft case), not NASA's 0.5.
