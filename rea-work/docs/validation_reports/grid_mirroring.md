This is a list of printed output; it does not say that the input field is mirrored, and θ = 0 is the bottom centerline in Fig. 2 while the input has no points other than ℓ = 1…10. The wording is **unresolved**: no text reads it as an instruction to mirror the field.
- **CR-3813 §3.4, p. 27:** "In the present model, the grid is confined to the side of the fuselage where the propeller is located." Ψ_G (Eq. 42) is the sum over these grid points m = (k, ℓ).

## Decision

The production code already does this (`generalized_force_sums` sums the 160 points). The item 7 wording stays recorded as unresolved and is not read as a mirroring instruction.
