DECISIONS ALREADY MADE
- Wu/Russell removed. Sources: BBN/Wilby first (NASA CR-158919 static, CR-159124 taxi) for phase; NACA Report 996 for amplitude (M_t 0.45-0.90 only); Pereira second as forward-flight check (phi=0 deg, harmonics 1-2, +/-1.7 dB).
- e11 (NASA measured data) is a validation test only, not a user option. The only user source is BEMT + F1A.
- GEXT (grid extension: cosine falloff + geometric phase delay) is an importance bound, not a validation; unfalsifiable on l=1; circularity not measured. T2 cannot constrain GEXT. Code options (falloff_exponent, falloff_floor, delay_scale) and a testset were added but NEVER RUN.
- Cabin chain is NASA test-article-specific (1.016 m, Phase III trim). Aircraft cabin is a different instance with user inputs (e.g. 2.64 m diameter is a default; user can change it). Calibrated values do not transfer.
- Uncertainty plan (phase 23): epistemic band, not a confidence interval; untuned parametric coverage check (23e); a-priori ranges: trim loss 0.3-1.2, tonal structural loss 0.02-0.10; provenance tags; no pass thresholds, report the band only.
- Paper confirmed: f'(n,r) = (1/A) * integral_A phi_n(x) psi^r(x) dx, Eq.(45), CR-3813 printed p.32 (PDF page 42). Psi_G discrete form is Eq.(42) (pp.26-27). Eq.(52) is the trim version.
