T1 FAIL CASE - HOW TO CHANGE THE CODE
=====================================
Date: 2026-10-20
Applies to: rea-work\PAIN.jl\src\pain_core.jl, function tone_mean_square_pressure

1. WHAT IS WRONG
----------------
The sidewall trim is counted twice in the tone sum.

  fpr  = coupling_factor(ac, st, inp.fuse; tau_t = T^2)   -> shell term carries sqrt(T^2) = T, so fpr^2 carries T^2
  term = ... * (T^2) * (fpr^2) * ...                       -> a second T^2

So the shell path is multiplied by T^4 instead of T^2. This was introduced
with the Eq. (52) coupling change on 2026-10-20 (the old coupling had no
tau_t, so T^2 appeared once and the old calibration was built on that).

CR-3813 Eqs. (7)-(8) (printed p. 15): "tau_ML^H and tau_t^H (in f'(n,r)) are
evaluated at omega_H". tau_t appears ONLY inside f-bar' (Eq. 52), on the shell
term, as sqrt(tau_t). There is no separate trim factor in Eq. (8).

Estimated size of the double count (surrogate T from trim_T_fc):
  H1 200 Hz  T = 0.39  -> -8.2 dB
  H2 400 Hz  T = 0.21  -> -13.5 dB
  H3 600 Hz  T = 0.14  -> -16.9 dB
(upper bounds: the floor term of f-bar' is not scaled by T)

Current T1 (docs\validation_reports\t1_tonal.md): H1 80.27 PASS (via NASA +/-4),
H2 54.45 FAIL, H3 51.50 FAIL. Expected after the fix, roughly: H1 ~88.5,
H2 ~68, H3 ~68.4. H2 will probably still FAIL (measured mean 80, NASA 75.5).
That remaining gap is NOT fixed by tuning (see section 5).


2. THE CODE CHANGE (fix "b": CR-3813 form)
------------------------------------------
File: rea-work\PAIN.jl\src\pain_core.jl, inside tone_mean_square_pressure.

Replace:

            term = (ρ0 * c0^2 / V) * (T^2) * (fpr^2) * (Ψ^2) /
                   (max(st.M_r, 1e-9)^2 * max(ωH, 1.0)^2) * Wn * Wr

with:

            # τ_t enters only through f̄' (√τ_t on the shell term, Eq. 52);
            # no separate trim factor (CR-3813 Eqs. 7-8)
            term = (ρ0 * c0^2 / V) * (fpr^2) * (Ψ^2) /
                   (max(st.M_r, 1e-9)^2 * max(ωH, 1.0)^2) * Wn * Wr

Keep the line  fpr = coupling_factor(ac, st, inp.fuse; τ_t=T^2)  as it is
(T is an amplitude-type surrogate, so T^2 is read as the power coefficient
tau_t; this reading is already recorded in the plan, step 17c).

Also update the docstring just above the function: change
  "<p²>_H ≈ Σ_n Σ_r (ρ0 c0² / V) * T_fc² * f'² * |Ψ_G|² / M_r²"
to
  "<p²>_H ≈ Σ_n Σ_r (ρ0 c0² / V) * f̄'²(τ_t = T²) * |Ψ_G|² / M_r²"

Do NOT change: broadband_cabin_p2 (it uses T^2 once, no f̄', so it is not
double counted), trim_T_fc, the loss-factor curves, bb_j2_scale, GEXT.

Line endings: pain_core.jl is CRLF; keep it CRLF.

---------------------------------------------
Do not adjust eta, T, trim masses, bb_j2_scale, GEXT or the grid until H2
passes. T1 is compared against E-16, so that would be tuning to the test data
(VALIDATION_GUIDELINE rule: no tuning to delta 0; criteria fixed before
comparing). If H2 still fails after the fix, record it as a result.

The remaining H2 gap is closed (or measured honestly) by the planned phases,
in order (docs\IMPLEMENTATION_PLAN.md):

  16a  App. A trim, tau_t = |a11|^-2 + tau_t^m (Eq. A.22). Prototype tau_t at

  16b  Loss factors: eta_n Eq. (77); eta_r = C/f_r + eta_rad (Eqs. 79-81);
       eta_r' Eq. (82); eta_r'' Eq. (83). Replaces the E-14/E-15 curves.
  17a  Tone pressure exactly Eq. (8) summed by Eq. (3): includes the rigid-body
       cabin mode (the surrogate skips it) and the axial modes q > 0
       (q_convergence.md: +3.3 dB at H2 on the surrogate sum).
  18a  Re-run T1/T2 with no tuning; the result is recorded whatever it is;
       the T1/T2 tests record instead of asserting PASS.

(75.5 vs 80), so part of the H2 gap may be inherent to the method.
